# Freelancer Auto Bid - Chrome Extension

Freelancer.com の新規プロジェクトを自動検出し、3〜10秒以内に入札を行う Chrome 拡張機能です。

## 機能

- **プロジェクト監視**: `https://www.freelancer.com/search/projects` をリアルタイム監視
- **自動フィルタ**: 入札者数50人以上のプロジェクトはスキップ
- **価格フィルタ**: 最低 $100 USD 以上のプロジェクトのみ入札（時給は時給×40時間で換算）
- **地域フィルタ**: インド・パキスタン・アフリカ諸国のクライアント案件を除外
- **言語対応**: 入札文は英語を標準とし、クライアントの広告言語に合わせて生成
- **高速入札**: 投稿から3〜10秒以内に入札完了
- **AI入札文生成**: Claude / OpenAI API で最大1500文字の提案文を生成
- **契約書自動署名**: IP Agreement / NDA の署名・氏名・住所を自動入力
- **問題自動解決**: エラー時にスクリーンショットをAIに送信して分析・解決
- **ダッシュボード**: 入札ステータス、統計、設定管理

## インストール

1. `node scripts/generate-icons.js` でアイコンを生成（Node.js が必要）
2. Chrome で `chrome://extensions` を開く
3. 「デベロッパーモード」を有効化
4. 「パッケージ化されていない拡張機能を読み込む」→ `extension` フォルダを選択
5. Freelancer.com にログインした状態で使用

## 使い方

1. 拡張機能アイコンをクリック → 「ダッシュボードを開く」
2. **API** タブで Claude / OpenAI API キーを設定
3. **入札** タブで入札額・納期・時給を設定
4. **プロフィール** タブで氏名・住所を設定（契約書署名用）
5. **ポートフォリオ** タブで過去のプロジェクトリンクを textarea に1行1リンクで入力
6. 「開始」ボタンで自動入札を開始

## ダッシュボード操作

| 操作 | 説明 |
|------|------|
| 開始 | 自動入札を開始 |
| 停止 | 自動入札を停止 |
| 保管 | 現在の設定を明示的に保存 |
| 変更 | 変更を適用して保存 |
| 削除 | 設定を初期値にリセット |

設定は入力のたびに自動保存されます（1.5秒デバウンス）。

## 入札フロー

```
プロジェクト一覧監視
  → 新規プロジェクト検出
  → 入札者数 < 50 かつ 投稿3〜10秒以内
  → プロジェクトページを開く
  → AI で入札文生成（1500文字以内）
  → フォーム入力（金額/納期/提案文）
  → Place Bid クリック
  → IP Agreement が表示された場合
     → 署名・氏名・住所を自動入力
     → Submit Document
  → 問題発生時: スクリーンショット + AI分析で自動解決
```

## 注意事項

- Freelancer.com の利用規約を確認し、自動化が許可されているか確認してください
- API キーはローカルストレージに保存されます。他人と共有しないでください
- サイトの DOM 構造が変更された場合、セレクタの更新が必要になる場合があります
